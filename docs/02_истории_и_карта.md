# 2. Продукт и User Story Map

## 2.1 Миссия и видение

- **Миссия (из питча, слайд 7):** помочь обмениваться идеями «куда можно сходить» между близкими по духу людьми.
- **Видение (С — в питче нет отдельной формулировки):** выбор места для встречи начинается не с поиска среди отзывов незнакомцев, а с карты мест, которые советуют люди, чьему вкусу ты доверяешь.
- **Границы (слайд 7):** не заменяем 2ГИС и Яндекс Карты; не сервис передачи текущей геолокации.

## 2.2 Типы пользователей

| Тип | Источник |
|---|---|
| guest — гость | C4, уровень 1 |
| user — авторизованный пользователь | C4, уровень 1 |
| student — студент или выпускник, 18–23 | питч, слайд 3 |
| young professional — молодой специалист, 22–30 | питч, слайд 3 |
| couple / friends group — пара или компания, 25–34 | питч, слайд 3 |
| moderator — модератор / администратор | C4, уровень 1 |
